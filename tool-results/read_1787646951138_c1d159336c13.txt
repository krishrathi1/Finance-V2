   480→/* One animation on <main>, never two.
   481→   `.page-enter` (page-content-enter) and this rule both animate `transform`
   482→   on the same element during a navigation. Two transform animations on one
   483→   element don't blend — the cascade picks a winner mid-flight while the
   484→   children are separately sliding via `.stagger-fade`, which is what read as
   485→   jitter. During a route change this is the only animation on <main>; on a
   486→   cold load, where the attribute is absent, `.page-enter` still runs. */
   487→html[data-route-transition="active"] main.page-enter {
   488→  animation: route-soft-settle 360ms var(--ease-route);
   489→  will-change: opacity, transform, filter;
   490→}
   491→
   492→/* Fade children in place on a route change instead of sliding them.
   493→   The staggered translate is a nice first-load flourish, but replaying a
   494→   14px lift on up to 12 children — with delays running to ~300ms — on every
   495→   navigation stacks movement on top of <main>'s own animation. Opacity alone
   496→   keeps the entrance without anything shifting position. */
   497→html[data-route-transition="active"] .stagger-fade > * {
   498→  animation-name: stagger-fade-in-place;
