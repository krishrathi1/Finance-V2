## Deviations / notes for integrator
- Exports are exactly `WatchlistView`, `PortfolioView`, `AlertsView` from the file paths above — import them in the app shell view switcher (`view === "watchlist" | "portfolio" | "alerts"`).
- StockSearch keeps its built-in "Analyze" submit button (shared component, not modified); inside dialogs/forms it acts as the select action.
- Portfolio risk-scan card is always rendered; its button only appears when holdings exist (mirrors the digest pattern). Allocation pie + table + summary only render when holdings exist (empty state otherwise).
- `worst` performer chip is hidden when it equals the best (single holding).
- Distance chip uses `Math.abs(...).toFixed(1) + "% away"` (fmtPct would force a "+" sign on an absolute distance).
- TS (`bunx tsc --noEmit`) and ESLint pass with **zero errors in these three files** (pre-existing errors exist elsewhere in src/server, examples/, skills/, upload/).
